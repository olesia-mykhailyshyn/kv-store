# M1, завдання 8: відтворюваність — знести і підняти з IaC

> Prove recreatability: tear the whole stack down and bring it back from IaC alone. Record how long it took and what broke on the first attempt.

- Шаблон: [`infra/network.yaml`](../../infra/network.yaml) (стек `kv-network`, 18 ресурсів, 10 експортів)
- Скрипт: [`scripts/recreate-network.sh`](../../scripts/recreate-network.sh)
- Регіон `us-east-1`, профіль `kse-lab`, 2026-11-01

## Як

```bash
./scripts/lab-login.sh            # ключі нової сесії
./scripts/recreate-network.sh     # знести (якщо є) → підняти з шаблону → 9 перевірок → час
```

| Етап | Команда | Що робить |
|---|---|---|
| 0 | `aws cloudformation validate-template` | шаблон правильний |
| 1. Знести | `aws cloudformation delete-stack` + `wait stack-delete-complete` | CloudFormation видаляє всі 18 ресурсів стека |
| 2. Підняти | `aws cloudformation deploy --template-file infra/network.yaml --stack-name kv-network --tags Project=kv-store Milestone=m1` | CloudFormation створює change set і одразу виконує його |
| 3. Перевірити | `describe-route-tables`, `describe-subnets`, `list-stack-resources`, `list-exports` | 9 перевірок за spec `network` |

Жодних кроків у консолі — лише шаблон і команди.

## Що зламалося з першої спроби

**У самому перестворенні — нічого:** обидва запуски скрипта пройшли з першої спроби, 9/9 перевірок. Чесно про те, що «ламалося» довкола:

| Що | Що сталося | Як виправили |
|---|---|---|
| Ресурси не пережили сесію | Платформа AWS Academy видалила стек у кінці сесії — я помилково вважала, що ресурси зберігаються | Знайшли через `list-stacks` і CloudTrail; виправили документи; відтворюваність з IaC стала щосесійною процедурою |
| Команди в zsh | `$P` / `$c` з кількох слів zsh не розбиває на окремі аргументи (`Unknown options: --profile kse-lab`); `$ACC:role` — zsh-модифікатор `:r` зіпсував ARN | Явні аргументи і `${ACC}`; скрипти пишемо на **bash** (`#!/usr/bin/env bash`) |
| Маршрут до IGW (попереджено, не зламалось) | `!Ref InternetGateway` чекає лише на створення воріт, а не на приєднання до VPC → маршрут міг би впасти | `DependsOn: InternetGatewayAttachment` у шаблоні з самого початку |
| Видалення з імпортами (на майбутнє) | Поки стек M2 імпортує `kv-network-…`, `delete-stack` мережі впаде | Видаляти у зворотному порядку: спершу стеки M2 (ADR-002) |

## Висновки

- Мережа повністю описана кодом: знести й підняти — одна команда, ≈ 100 с, без ручних кроків.
- У цій пісочниці це не вправа, а **початок кожної сесії** (ресурси видаляються в кінці сесії).
- Для M2: час розгортання усієї системи (мережа + сервіси) треба тримати малим — сесія лише 3 год; CI/CD має вміти піднімати все з нуля.
